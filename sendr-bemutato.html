📱 Sendr – Telefonról PC-re küldés

Sendr egy Firefox-kiegészítő: szöveget és linkeket tudsz küldeni a telefonodról a számítógépedre (vagy fordítva), saját, titkosított háttérszolgáltatás használatával. A bővítmény nem gyűjt adatot; minden a te backendeden fut.

Működés röviden

  • Telefonon: megnyitod a Sendr bővítményt, beírod a szöveget, Küldés.
  • PC-n: megnyitod a Sendrt, Lekérés → a tartalom vágólapra vagy a fókuszban lévő mezőbe kerül.
  • A tartalom titkosítva megy át; az API kulcs és a titkos kulcs csak nálad van.

Backend felállítása (Cloudflare Worker)

A Sendrnek kell egy kis API (backend). Ezt egy Cloudflare Worker + két KV tároló biztosítja. Az alábbi lépéseket egyszer kell megcsinálni.

1. Cloudflare fiók és Wrangler

Ha még nincs: regisztrálj a Cloudflare-n. Telepítsd a Wrangler CLI-t (Node.js kell hozzá):

npm install -g wrangler
wrangler login

2. KV tárolók létrehozása

Két KV namespace kell: egy az API kulcsokhoz, egy az üzenetekhez.

wrangler kv:namespace create "TRANSFER_STORES"
wrangler kv:namespace create "TEXT_BUFFER"
wrangler kv:namespace create "TEXT_BUFFER" --preview

A parancsok kiírják az id-t. Ezeket a következő lépésben használod.

3. wrangler.toml és Worker kód

Hozz létre egy mappát a Worker projekthez. Benne egy wrangler.toml példa (cseréld ki a id értékeket a saját KV id-dre):

name = "sendr-api"
main = "workers.js"
compatibility_date = "2024-01-01"

[[kv_namespaces]]
binding = "TRANSFER_STORES"
id = "IDE_ide_TRANSFER_STORES"

[[kv_namespaces]]
binding = "TEXT_BUFFER"
id = "IDE_ide_TEXT_BUFFER"

[[kv_namespaces]]
binding = "TEXT_BUFFER"
preview_id = "IDE_ide_TEXT_BUFFER_PREVIEW"

A workers.js fájl a Sendr projektben található (ugyanaz a mappa, ahol ez az oldal forrása is lehet). Másold be a workers.js tartalmát ebbe a mappába.

4. API kulcs regisztrálása a KV-ban

Válassz egy titkos jelszót – ez lesz az API kulcsod. Regisztráld a TRANSFER_STORES KV-ban (a YOUR_API_KEY helyére ezt a jelszót írd, a user1 bármi lehet, pl. default):

wrangler kv key put --binding=TRANSFER_STORES "api:YOUR_API_KEY" "user1"

Fontos: A Sendr bővítmény Beállításokban az „API kulcs” mezőbe a YOUR_API_KEY értékét (tehát ezt a jelszót) kell beírni – az api: prefix nem kell.

5. Worker deploy

wrangler deploy

A deploy után megkapod a Worker URL-jét (pl. https://sendr-api.xyz.workers.dev). A jelenlegi Sendr bővítmény egy előre beállított URL-t használ; ha a saját Workerödöt akarod használni, a bővítményt saját példányban kell módosítani (BASE_URL), vagy a bővítmény készítője később támogatja a saját URL megadását.

Sendr bővítmény

A bővítményt a Firefox bővítmények oldaláról (addons.mozilla.org) telepítheted, vagy ideiglenesen a manifest.json betöltésével (about:debugging). Beállításokban add meg az API kulcsot és a titkos kulcsot (ezt te találod ki, ugyanaz kell legyen mindkét eszközön).

Adatvédelem

A Sendr nem gyűjt és nem küld adatot a fejlesztőnek. Az API kulcs és a titkos kulcs csak a te eszközödön tárolódik. A küldött szöveg titkosítva megy a te backendedre (Cloudflare Worker); a fejlesztő nem fér hozzá.
